隱私政策

Aster Loop / 星環漫遊 · Android 包名 com.asterloop.game
生效日期：2026 年 9 月 7 日
發行者：Corzfree（個人開發者）

遊戲進度保存在你的裝置。我們沒有遊戲帳號或雲端存檔服務；廣告服務則會處理部分裝置與使用資料。本政策說明兩者的差別，以及你可以採取的選擇。

1. 適用範圍

本政策適用於 Aster Loop 星環漫遊、相關客服郵件及本遊戲支援頁面。星環漫遊是一款單人街機遊戲，無須註冊帳號；沒有由開發者營運的線上排行榜、遊戲分析伺服器或應用程式內購買功能。

2. 儲存在裝置的遊戲資料

遊戲使用 Android 應用程式儲存空間，保存分數、星塵、已解鎖外觀、里程碑、每日成績及偏好設定。這些存檔不會上傳至 Corzfree 營運的伺服器。遊戲已停用 Android 雲端備份及裝置間的應用程式資料轉移。

正在進行的一局僅保留在記憶體中，程序結束後不會恢復。已累積進度會在相關遊戲轉場儲存；若程式意外停止，尚未儲存的變更可能遺失。

3. 廣告與 Google 服務

遊戲整合 Google AdMob 與 Google 使用者訊息平台（UMP），以廣告支持遊戲開發。激勵廣告會先說明你選擇觀看後可獲得的遊戲獎勵；插頁式廣告可能在符合條件的局間轉場出現。一般遊玩不以選擇觀看激勵廣告為必要條件。

依 Google 的行動廣告 SDK 揭露，該服務會處理網路位置訊號、廣告或應用程式互動、技術診斷，以及廣告或其他裝置／帳戶識別碼，用於廣告投放、成效衡量及防止詐欺；SDK 傳輸的資料會經過加密。詳見 Google SDK 資料揭露、Google 隱私權政策及 Google 如何使用來自應用程式的資料。

隱私訊息和選擇會依地區與適用要求有所不同。遊戲提供該選項時，可從「設定 → 隱私選項」重新開啟支援的同意選擇。拒絕個人化廣告，不一定停止所有與廣告相關的資料處理；Android 的廣告 ID 設定也提供其他控制。當無法滿足同意或連線要求時，廣告可能無法使用，但仍可正常遊玩。

Corzfree 透過 AdMob 取得廣告報表。Google 及相關廣告參與者依其適用政策處理資料，處理地點可能位於你所在國家以外。遊戲不會把本機分數或錢包存檔送至 Corzfree 的後端作廣告用途。

4. 客服郵件與網站

當你寄信給我們，我們會收到你主動提供的郵件地址、內容及附件；客服信箱使用 Gmail。這些資訊用於答覆請求、排查問題及處理隱私請求；不會只因你聯絡客服，就把你加入行銷名單。郵件會依解決和記錄請求或履行適用義務所需而保留；你可透過下方聯絡方式，要求刪除我們控制的相關郵件。

這些頁面使用 GitHub Pages 託管。連線至託管服務時，GitHub 可能取得 IP 位址、瀏覽器資訊等連線資料，詳見 GitHub 隱私聲明。本遊戲頁面沒有額外加入開發者分析工具、廣告標籤、表單處理服務或第三方字型載入器。開啟外部連結後，適用該服務的資料處理方式。

5. 保存與刪除資料

本機進度會保留至你清除應用程式資料或解除安裝。可至「Android 設定 → 應用程式 → Aster Loop → 儲存空間 → 清除儲存空間」操作，名稱會因裝置而異。這會清除進度、外觀及偏好設定，無法透過遊戲復原。本版本沒有遠端遊戲帳號，也沒有遊戲內重設按鈕。

清除遊戲資料不會同時刪除 Google、GitHub 或郵件服務已持有的資料；各服務的保存及控制方式，請參閱其政策。關於 Corzfree 控制的資料或客服郵件，請寄信至 free4564567@gmail.com，以「Aster Loop Privacy Request」為主旨，說明希望存取、更正或刪除的資訊。我們可能要求核實請求所需的資料，並依適用法律回覆；無法承諾代為刪除獨立服務商控制的紀錄。

6. 使用年齡與權限

星環漫遊為 13 歲以上的一般使用者設計，並非面向 13 歲以下兒童的服務。預定使用年齡不代表每位使用者在其所在地均已達到法定同意年齡。若家長或監護人認為兒童直接向 Corzfree 提供了個人資訊，可聯絡我們，以便查核並在適當情況下刪除我們控制的資料。

遊戲不要求提供姓名、密碼、精確 GPS 位置、聯絡人、相機、麥克風、照片或付款資訊。廣告服務仍可能處理前述裝置或帳戶識別碼。

7. 你的選擇與權利

依所在地法律，你可能享有存取、更正或刪除個人資料、限制或反對特定處理、撤回同意，或向隱私主管機關提出申訴等權利。由 Corzfree 控制的資訊可向我們提出請求；Google 持有的廣告資料則可使用前述 Google 資源中的控制。撤回同意不影響撤回前處理的合法性。

在適用情況下，客服資料處理基於提供你所請求的服務，以及回答詢問、維護遊戲的合法利益；需要同意的廣告處理會依要求取得同意。服務商會在其政策中說明自身處理目的及法律依據。

8. 安全與政策更新

遊戲使用 Android 的應用程式儲存保護。沒有任何儲存或傳輸方式能保證絕對安全。若資料處理方式改變，我們會更新此頁及生效日期，並在適用要求下另行通知。
